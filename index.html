Sobre

Minha jornada em desenvolvimento

Este projeto foi desenvolvido por uma aluna do curso Técnico em Desenvolvimento de Sistemas. O objetivo é apresentar um trabalho profissional que também sirva como portfólio para o LinkedIn.

As principais disciplinas que participaram do desenvolvimento deste site foram:

  • Computação Gráfica
  • Análise e Projeto de Sistemas
  • Ciência de Dados
